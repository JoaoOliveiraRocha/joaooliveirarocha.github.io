What's in the box

What does it provide us?

A way to use an LLM for coding.

On its own, an LLM is one stateless function: text in → text out.

It can't open a file, run commands, directly.

That loop is the harness. Provides the tools for the LLM to fulfill our request.

~60s. Technical beat. The model API is stateless: every call re-sends the whole history (system prompt, project instructions, tool definitions, all previous turns and tool results). Tools are just JSON schemas the model can "call" by emitting structured output; the model never executes anything, the harness does, then feeds the result back. Everything else (TUI, diffs, permissions, sessions, MCP, sub-agents) is detail on top of this loop. Also the reason token usage is a harness problem: every iteration pays for the whole history again.
