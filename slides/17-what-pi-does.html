So what does Pi actually do?

Basically a bash shell with conscience?

  • 🚫 No permission popups — YOLO by default; containerize it if you want walls.
  • 🔎 No web search — install a package?
  • 🔗 No MCP — kinda
  • 🗺️ No plan mode — write the plan to a file
  • 🤖 No sub-agents — tmux, or an extension
  • ⏱️ No background bash — tmux
  • 📝 No to-dos — a TODO.md

(Don't panic: each one is a package away.)

~60s. This is the "what we didn't build" list from pi.dev. MCP used to be on it and isn't any more (1.0 added it). Web search: e.g. the pi-web-access package. Leave the panic beat for a laugh, then move on.
