Properties of a good agent task

What makes a task good for an agent?

At least that's how I think. Ten properties; three matter most.

Clarity on Scope

Do we know what to build?

  • Clear objective — prevents solving the wrong problem.
  • Bounded scope — prevents unnecessary refactoring / side-effects.
  • Clear constraints — avoids unwanted design decisions. What should NOT be done"

Testable / Verifiable End Conditions

Can we prove it works?

  • Verifiable outcome — So agent can verify if success (ACs aren't sufficient)
  • Deterministic feedback tools — provide access to run tests, linters, LSP. Reliable correction loops

Autonomy

Can the agent execute it alone?

  • Sufficient Context — Remove guessing / hallucination. "Ask" tool is a must.
  • Low external dependency — few human decisions or approvals, so it can run on its own

Containment

Can mistakes be isolated / reverted?

  • Reversible changes I advice to not let it mutate git commits, messages, terraforms, etc.
  • Observable progress — intermediate results you can inspect
