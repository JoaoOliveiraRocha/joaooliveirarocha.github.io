Under the hood

What does an harness give the model?

Five things the LLM can't do alone:

  • 👁️ Eyes — decides what the model sees: system, AGENTS.md, file reads.
  • ✋ Hands — changes files, shell commands, drive a browser, requests to Jira MCP or Github...
  • 🛡️ Guardrails — permissions, approvals, sandbox, undo
  • 🧠 Memory — sessions, history, resume, notes
  • 🔁 The loop — keeps going until done

❌ Intelligence. That comes from the model.

~45s. Don't define "harness" up front; start from what they already use daily and stopped noticing. Claude Code, Copilot CLI, OpenCode, Codex are all harnesses. The list mirrors LangChain's anatomy of a harness (filesystem, bash, sandbox, memory, compaction, skills, loops). Last click sets up the next slide: if none of this is the intelligence, does a better harness make the agent smarter?
