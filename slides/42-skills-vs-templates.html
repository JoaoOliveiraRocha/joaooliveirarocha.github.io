Two reusable things

Skills vs. prompt templates

Skill Prompt template
Good for Know-how the model should reach for on its own A re-occuring procedure or task / avoid re-typing
What it is A folder with a SKILL.md One Markdown file
Who triggers it The model mostly (sometimes the user) Usually by typing /promt-name. (Model but less sensitive).
Arguments No Yes: $1, $2, etc. Some mandatory

SKILL.md is a shared format: Pi, Claude Code, OpenCode, Copilot CLI and omp all read it.

Skills and templates are indexed when a session starts. Added one? Start a new session or /reload.

~75s. If someone only remembers one thing: a prompt template is a saved prompt with blanks. A skill is a saved capability the model decides to load. The shared SKILL.md format is the Copilot-relevant part: what you write here carries over. The gotcha is real: a skill written mid-session says "Unknown skill" until the next session boots.
