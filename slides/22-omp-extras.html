The rest of the box

  • ⚓ Hashline edits — the model points at content-hash anchors; stale edits are rejected. OpenAI models write by patch-based. Anthropic usually do string replacement. (patch "suits" better OMP)
  • 🧩 LSP on every write — renames update imports before the file moves
  • 🐞 Real debugger — lldb, dlv, debugpy: step, inspect, evaluate
  • ⏰ Time-traveling rules — a rule fires only when the model goes off-script
  • 🎯 Advisor model — a second model reads every turn
  • 🤝 /collab — share a live session with a link
  • 🧠 Memory — the agent curates facts across sessions
  • 🦀 Native core — ~80k lines of Rust: ripgrep, glob and coreutils in-process
