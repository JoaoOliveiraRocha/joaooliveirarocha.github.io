What if I need extra things?

Disclaimer: Pi is actually not that simple and has extra stuff. We're just simplifying.

  • 🛠️ Build it yourself! — Pi ships with its own documentation, so just ask it. Example: my undo/redo, then /reload.
  • 📦 Use a 3rd-party package — straight from the Pi marketplace: pi install npm:pi-web-access. 5,000+ published.
  • 📜 Or something lighter — a skill or a prompt template: plain markdown, no code.
  • 🔌 Or plug in what already exists — MCP servers, native since 1.0.
