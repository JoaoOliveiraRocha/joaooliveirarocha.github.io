The three that matter most

Scoped. Verifiable. Autonomous.

Property ❌ Bad ✅ Good
Well-scoped The agent knows exactly where the task begins and ends. “Improve the authentication system.” “Add token-expiration validation to auth/middleware.ts, without changing the login flow.”
Verifiable Success is a concrete check, not the agent's opinion. “Make the API more robust.” “Return HTTP 400 for malformed input, add regression tests, and ensure the existing API tests pass.”
Autonomously executable The agent has the information, environment, tools and permissions to finish. “Integrate our payment provider.” “Using the existing payment client and sandbox configuration, implement webhook signature validation against the documented payload format.”
~90s. Two clicks per row: first the property and the bad example (let the room feel the ambiguity), then the good one. My own tips, if there's time: don't blindly trust ACs from Jira (some are a year old and written by non-engineers); ask for a plan first so you both know what the solution looks like; if you can't explain "defense in depth" or "theta-style joins", don't ship it; rubber duck the problem and ask for pros and cons; tests are the cheapest proof; templates give a shape to fill instead of a blank page; reproduce the user's case with the same conditions and steps.
