Small trick

Magic keywords

One lowercase word in your prompt changes how the agent works.

  • 🧠 ultrathink — maximum reasoning depth
  • 🎼 orchestrate — parallel subagents, each phase verified
  • ⚙️ workflowz — build a repeatable multi-subagent workflow
  • 📋 jevify — bulk-classify a long list in one batch (commit audits, log triage)*

Need another reserved keyword (yolo? p.e.) -> just ask it

No flags, no config. Just type the word.

~45s. Point: you steer the agent in plain prose, not through settings. In omp's editor each keyword is animated with its own gradient while you type it, and stays highlighted in the sent message; that's what the colours here mimic. The keywords only trigger in prose, not inside code spans or paths. Proof it's real: "orchestrate" fired while this very deck was being built and injected a hidden notice ("Execute as orchestrator under this contract; it overrides tendencies to yield early, narrate, or do the work yourself.") followed by ~40 lines of rules. Neither Copilot CLI nor bare Pi documents anything like it.
