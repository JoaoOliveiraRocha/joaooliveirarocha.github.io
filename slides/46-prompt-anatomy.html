# CVE / Dependency Fix

Jira ticket: $1 (mandatory, a link). Extract the ticket id ...
Goal: $2 (mandatory) - short description of what's wanted ...
Wiz finding: $3 (optional) - a Wiz link or a pasted finding ...
Extra instructions: ${@:4}

If $1 or $2 is missing or ambiguous, ask the user (ask) before proceeding - do not assume.

## 1. Research (web_search required)
## 2. Decide: easy fix or not
... stop, do not touch any file. Report affected package(s) ...
## 3. Apply (only if step 2 says easy fix)
## 4. Branch
## 5. Commit
## 6. PR
  1. Frontmatter — shows in the / menu, tells you what to type
  2. Arguments — $1 $2 $3, the rest as ${@:4}
  3. Steps — plain Markdown: the procedure I used to retype
  4. Guardrails — ask, don't guess; stop, don't touch anything

File: ~/.omp/agent/prompts/jr-cve-fix.md

~60s. Four clicks: each lights up one colour in the file and shows its legend entry (frontmatter, arguments, steps, guardrails). The frontmatter is the only "special" part; everything else is just the instructions you'd write in chat, with $1/$2 blanks. The guardrails come from mistakes: it must ask rather than invent a ticket id, and stop without touching files if the fix isn't trivial. Full file is ~100 lines (repo rules for branch/commit names, registry mirror handling, PR template, sprint-review block).
